Risques réels

  • !La blacklist apple_gmux et MODULES+=(t2gmux) s'appliquent à tous les noyaux. Un test A/B avec linux-t2-mbp161 n'est donc pas gratuit (même genre de piège mkinitcpio que le bug LUKS).
  • !amdgpu est figé sur 7.2.11 : les mises à jour de linux-t2 sont bloquées jusqu'au repackaging.
  • !Validé seulement sur Fedora, pas sur Arch avec Hyprland. Paquets Arch « with no support ».
  • !Titan Ridge (yuters 0005) n'est pas couvert côté Arch : la règle udev 0.2 reste nécessaire.
  • !Licence à vérifier. Je récupérerais le source à un commit précis plutôt que de le copier dans le repo.
